1. Project Vision & Architecture Overview

BAGANI (বাগানি) is an offline-first mobile application built for rooftop gardeners, balcony plant hobbyists, and urban agriculture enthusiasts. It eliminates the need for expensive hardware sensors by combining intelligent local botanical heuristics with online enrichment and cloud backup.

2. Core Functional Modules

1. Botanical Search & Auto-Correction Filter

Implemented in lib/services/online_botanical_service.ts and lib/core/components/botanical_search_modal.tsx. Automatically checks user input against an authoritative botanical catalog, fixes colloquial or misspelled entries (e.g. "sabeda" → "সফেদা / Sapodilla"), and enriches plant profiles with optimal soil pH, humidity, and sunlight data.

2. Dual-Tab Plant Profile & Precision Pruning

Implemented in lib/screens/plant_profile/plant_profile_screen.tsx and lib/services/precision_pruning_service.ts.

  • Tab 1 (Care & Organic Remedies): Real-time hydration estimates, harvest countdown, organic pest remedies (Neem oil, wood ash, garlic spray), and a checkbox care timeline.
  • Tab 2 (Precision Pruning for 2x Yield): Step-by-step 1G, 2G, and 3G pruning regimens tailored to climbing gourds, tomatoes, chilies, and citrus trees.

3. Hyper-Local Climate Advisory

Implemented in lib/screens/weather_care/weather_care_screen.tsx. Synthesizes real-time microclimate conditions across all 64 districts in Bangladesh to recommend season-appropriate crops.

4. Remotely-Updatable Directory & Community Vault

Implemented in lib/screens/directory/directory_screen.tsx. Provides verified contacts for regional agriculture officers and nurseries, alongside a community tip vault with upvoting.

5. Custom Navigation & Settings

5-tab bottom navigation dock with a specialized light-white unselected tile and vibrant green active indicator for the Scan action. Clean segmented toggles for Bengali/English and Light/Dark mode.
